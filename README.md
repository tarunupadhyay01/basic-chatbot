# Basic Chatbot 🤖

A simple Python-based chatbot created using Python.

## Features

- Greets the user
- Responds to basic questions
- Tells the chatbot's name
- Responds to "How are you?"
- Says goodbye when the user types "bye"

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download this repository.
3. Open the project folder.
4. Run the following command:

```bash
python "basic chat.py"
